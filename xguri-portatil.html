Se a Versão 2 encerrar

Se aparecer a tela de recuperação, use Compartilhar diagnóstico para registrar o erro. Para voltar, abra esta página pelo navegador, baixe a Versão 1 da atualização 1.35 e instale por cima. Não desinstale o XGuri nem limpe os dados.

Baixar Versão 1 para voltar

Troque de versão dentro do aplicativo

  1. Abra Configurações → Dispositivos da outra versão.
  2. Confira as duas listas e toque em Quero usar essa versão junto da versão desejada.
  3. O XGuri baixa o arquivo correspondente. Confirme a instalação solicitada pelo Android.
  4. Abra o XGuri novamente. Para voltar à outra versão, use a mesma tela.

A troca mantém os dados e funciona mesmo quando as duas opções têm o mesmo número de atualização.
